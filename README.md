# 🚀 자동차 경주

## 📄 기능 목록 구현
### 1. 입력 처리
**[입력] 경주할 자동차 이름 입력받기**   
➤ Console.readLineAsync() 사용  
➤ 쉼표(,) 기준으로 이름 분리

**[검증] 자동차 이름 입력값 검증**  
➤ 이름이 5자 초과일 경우 예외 발생  
➤ 빈 문자열 또는 중복 이름 입력 시 예외 발생  
➤ [ERROR] 메시지 출력 후 프로그램 종료  

**[입력] 시도할 횟수 입력받기**   
➤ 숫자 형태의 입력인지 검증  
➤ 1 이상 정수만 허용  
➤ 유효하지 않을 경우 [ERROR] 메시지 출력 후 종료

### 2. 경주 로직
**[초기화] 자동차 객체 리스트 생성**  
➤ 각 이름으로 Car 객체 생성  
➤ 초기 위치는 0으로 설정  

**[전진 조건 판단]** 
➤ MissionUtils.Random.pickNumberInRange(0, 9) 호출  
➤ 4 이상일 경우 전진, 미만이면 정지  

**[이동 수행]**  
➤ 각 차수마다 모든 자동차에 대해 전진 조건 판단  
➤ 전진한 자동차의 위치를 1 증가  

**[라운드 결과 출력]**   
➤ 각 차수 종료 시 출력  
➤ 차수별 결과 출력 후 빈 줄 추가 

### 3. 결과 및 종료
**[우승자 판별]**  
➤ 가장 멀리 간 자동차의 거리 계산  
➤ 해당 거리를 가진 모든 자동차 이름을 추출  
 
**[우승자 출력]**  
➤ 우승자가 여러 명일 경우 쉼표(,)로 구분  ➤

**[종료 처리]**  
➤ 게임 종료 후 Console.close() 호출  

### 4. 테스트
➤ 이름 입력 검증 테스트  
➤ 시도 횟수 입력 검증 테스트  
➤ 전진 조건(랜덤값 4 이상 시 이동) 테스트  
➤ 우승자 판별 로직 테스트
